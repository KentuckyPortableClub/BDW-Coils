# KPC on the iPhone

The old iPhone beta copy of the KPC app that lived here was retired on Nov 18 2026. The KPC app on your Windows PC now hands out
the iPhone page itself (`http://<PC address>:8731/phone/` at home, or your Tailscale address with `/phone/`), and that page is
always the same version as the PC.

This folder keeps only a short page that points there (index.html) and **[IPHONE-SETUP.md](IPHONE-SETUP.md)**, the setup guide.
