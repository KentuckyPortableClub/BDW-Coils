# KPC on the iPhone (beta)

The Kentucky Portable Club app as a web page for iPhone and iPad (there is no App Store app).
Open it in **Safari**, then **Share ⬆ → Add to Home Screen** so it opens like an app.

It runs your radio **through the KPC app on your Windows PC** (the PC has the radio on its USB cable): frequency, mode,
🎛 more controls, meters, 🔧 tune, hearing the radio, talking, the voice keyer and the PC's FT8. The log and the spots work here too.

**How to set it up: see [IPHONE-SETUP.md](IPHONE-SETUP.md).**

This website is a copy of the KPC app made by `tools/iphone/make-beta.sh` in the KPC-App repo (see BUILT-FROM.txt for which version).
Do not edit the files here by hand: change the app, then make the copy again.
